# Rust component cookiecutter

Renders a Rust-implemented F Prime component: `<Name>.fpp` (annotated `@ fprime-rust`), `<Name>.rs`, `CMakeLists.txt`
and `docs/sdd.md`. Use through `fprime-util new --component` with this directory configured as the component
cookiecutter in `settings.ini`, or directly: `cookiecutter lib/fprime-rust/cookiecutters/component`.
